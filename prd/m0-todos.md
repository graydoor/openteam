# M0 TODO 执行清单（第一个里程碑）

## 里程碑定义
- 里程碑：`M0`
- 时间：`2026-04-20 ~ 2026-05-03`（2 周）
- 目标：交付最小可运行框架（Orchestrator + Router + 2 个专家 Agent + 基础 Trace）
- 验收：可端到端完成一次“需求 -> 代码建议”演示链路

## M0 范围边界
- 必做：
- 单次 run 生命周期可执行（create -> route -> specialist -> output）
- Router 可对 3 类任务做基础分类（需求拆解/编码建议/代码评审）
- 至少 2 个专家 Agent（建议先做 `Planner` + `Coder`）
- 返回可追踪 `trace_id`，并落地基础结构化日志
- 不做：
- Session 持久化与上下文裁剪（M2）
- 审批与生产权限分级（M3）
- 完整观测面板和告警（M4）

## 里程碑退出标准（Go/No-Go for M0）
- Go：
- M0-01 ~ M0-20 完成率 >= 95%
- Demo 链路可稳定跑通（至少 3 次）
- 每次 run 均返回 `trace_id` 且可定位失败环节
- No-Go：
- Orchestrator 状态机不稳定（出现挂起 run）
- Demo 结果不可复现
- 出错无法定位到具体步骤
